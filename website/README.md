# MacQ website

The marketing site for [MacQ](../README.md), served at
[macq.birju.dev](https://macq.birju.dev). Astro, static output, no client-side
JavaScript.

## Develop

```sh
cd website
npm install
npm run dev      # http://localhost:4321
```

| Script            | What it does                                      |
| ----------------- | ------------------------------------------------- |
| `npm run dev`     | Dev server with hot reload                        |
| `npm run build`   | Type-check, then build static output into `dist/` |
| `npm run preview` | Serve `dist/` locally, exactly as deployed        |
| `npm run og`      | Re-render `public/og.png` from `scripts/og.html`  |

## Layout

One page, two columns. The hero sticks to the viewport while the column of app
shots scrolls past it. Below 900px they stack and the shots become a horizontal
strip; below 600px the type scales down.

```
src/
  site.config.ts        all the copy: headline, features, version, links
  lib/shots.ts          reads public/shots/ at build time
  layouts/Base.astro    <head>, meta tags, global stylesheet
  components/
    Hero.astro          left column: header, headline, CTA, feature list
    SiteHeader.astro    brand mark and the two nav pills
    Screenshots.astro   right column
    Shot.astro          one tile: video, image or placeholder
    BrandMark.astro     the Q glyph, shared by the header and the placeholders
    AppleGlyph.astro    Apple logo on the download button
  styles/global.css     every rule on the page
public/
  shots/                drop screenshots here, see its README
  favicon.png           generated from the app icon
  og.png                generated by npm run og
```

## Updating for a release

Change `version` in [src/site.config.ts](src/site.config.ts). The download URL
is built from it and follows the Makefile's `MacQ-<version>.dmg` naming and the
untagged-`v` release tags already on GitHub. Drop `releaseStage` to `null` when
MacQ is no longer alpha.

## Screenshots

The right column reads whatever is in [public/shots/](public/shots/), sorted by
filename, and falls back to placeholder tiles when the folder is empty. See
[public/shots/README.md](public/shots/README.md) for naming and formats.

## Deploy

`npm run build` writes a fully static `dist/` with no server runtime, so any
static host works. Point the host at this directory with build command
`npm run build` and output directory `dist`, then map `macq.birju.dev` to it.
